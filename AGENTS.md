# Работа с presentation-kit

Это автономная HTML-презентация Star Guard. Начните с README.md, docs/content.md, docs/quality-review.md и docs/development.md. Исторический контекст — docs/original-context.md; текущие инструкции находятся здесь и в docs/.

- Редактируйте src/ и data/, затем пересобирайте dist/index.html. Не редактируйте результат сборки вручную.
- Сохраняйте 12 слайдов, обе темы, исходные изображения и честные пустые поля команды/QR, пока пользователь не задаст новые данные.
- Не придумывайте факты о Star Guard, имена, роли, URL, хеши коммитов или номера issues.
- Прогон 12.11.2026 — предоставленные данные, не независимая проверка. Не превращайте score в вероятность и не скрывайте ложные срабатывания.
- Поддерживайте полностью автономный HTML, переносимые пути, reduced motion, печать и отмену таймеров.
- Проверки: python build.py; python -m unittest discover -s tests -v; node --check src/deck.js; python tests/browser_checks.py; python shots.py; python make_pdf.py.
- Если браузер недоступен, явно фиксируйте, что визуальная проверка не выполнена. Не заявляйте о просмотре кадров по результату одной сборки.
- README содержит общее описание и навигацию. Подробности — docs/.

- При генерации новой презентации самостоятельно подбирайте перемещающийся объект по предметной области и фиксируйте выбор в исходниках/конфиге. Звезда — образ Star Guard, не обязательный шаблон для всех тем. Не добавляйте выбор персонажа в интерфейс, горячие клавиши или параметры просмотра.

- Перед выдачей HTML запускайте `python scripts/package_delivery.py` после сборки. Прикладывайте полученный файл с хешем в имени; не переиспользуйте прежнюю ссылку на `index.html` для изменённой версии.
- Проверяйте смысл движения, видимые подписи кнопок, сенсорное управление, обе темы и отступы именно в выделенном состоянии. Критерии и границы проверок — в `docs/quality-review.md`.
