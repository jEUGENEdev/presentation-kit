# presentation-kit

Комплект для автономной HTML-презентации **Star Guard**, команды **StarChecker**, ИТМО DevDays Fall 2026. Двенадцать слайдов о продукте, архитектуре, эвристиках и тестировании. Светлая тема, GitHub-мотивы, исходные скриншоты продукта и анимации.

## Открыть презентацию

Скачайте [dist/index.html](dist/index.html) через **Download raw file** и откройте в современном браузере. Интернет и сервер не нужны. Файл содержит шрифты, изображения, стили и скрипты.
