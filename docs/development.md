# Разработка

## Устройство

- `src/shell.html` — оболочка, навигация, заметки, обзор.
- `src/slides.html` — смысл и композиция 12 слайдов.
- `src/theme.css` — стили экрана, адаптация сцены, движения и печать.
- `src/deck.js` — навигация, отмена анимаций, интерактивные примеры.
- `data/deck.json` — команда, ссылки и данные.
- `data/notes.json` — заметки, ключи совпадают с id слайдов.
- `assets/` — встроенные локальные изображения, шрифты, иконки.
- `build.py` — экранирование данных, подстановка шаблонов, сборка offline HTML.
- `scripts/browser.py` — обнаружение Chromium и ожидание шрифтов/изображений.
- `shots.py`, `make_pdf.py` — скриншоты и PDF.
- `tests/` — проверки сборки и поведения в браузере.
- `dist/index.html` — готовый результат, хранится в git вместе с исходниками.

## Обычная правка

1. Измените данные или исходник нужного слайда.
2. `python build.py`
3. `python -m unittest discover -s tests -v`
4. `node --check src/deck.js`
5. `python tests/browser_checks.py`
6. `python shots.py` и визуально просмотрите 12 кадров.
7. `python make_pdf.py`, проверьте страницы и выделение текста.
8. Коммитьте исходники и обновлённый `dist/index.html` вместе.

Сборка детерминирована: без текущего времени и случайных идентификаторов. GitHub Actions проверяет, что committed HTML совпадает с пересборкой. В тестах проверяются 12 слайдов, уникальные id, локальные ресурсы, экранирование, пороги, центрирование, клавиши, кнопки, свайпы, обзор, заметки, остановка циклов и reduced motion. Автоматическая геометрическая проверка не заменяет визуальный просмотр.

## Контракты runtime

`window.__go(index)` открывает слайд по нулевому индексу. `window.deckState()` возвращает текущее состояние для диагностики. В URL индексы начинаются с 1. Исторические id сохранены и не совпадают с порядком: `s1,s3,s2,s5,s4,s7,s6,s8,s9,s10,s11,s12`.

Не добавляйте `setTimeout`, `setInterval` или `requestAnimationFrame` вне централизованных обёрток. Иначе при переходах появятся фоновые анимации старых слайдов. Не перехватывайте Enter/Space на кнопках. Не используйте глобальный обработчик click, который навигирует после клика на ссылке. После свайпа синтетический click подавляется.

Сборка не ходит в сеть. HTML-строки из JSON экранируются; JSON в `<script type="application/json">` защищён от закрывающего тега. Пути QR ограничены директорией `assets/`. Встроенный SVG берётся только из версионированных исходников.

## Новая презентация

Этот репозиторий содержит Star Guard как рабочую презентацию и основу для следующей. Для другой темы замените `src/slides.html`, `data/*.json`, изображения и проверки, привязанные к числу участников/выборке. Он не выдаёт себя за универсальный генератор любых дек: текущие 12 слайдов и 16 результатов проверяются намеренно.

## Ограничения окружения первоначальной переработки

Локальный запуск Chromium в сессии подготовки ограничен политикой окружения. Поэтому локально проверены Python-сборка, тесты данных и синтаксис JavaScript; полный браузерный прогон и PDF поручены GitHub Actions. Итоговые статусы смотрите в Actions, а не считайте наличие workflow доказательством его успешного выполнения.
