## 1. Как пришли к текущему варианту (что не зашло)

1. **Gamma (через MCP-коннектор)** — три версии: анимированная `giqbl4qc8fmb0e3`, минималистичная `msaawoj34r3uo7q`, v3 `6rl8rcgsxg24cbm`. **Не понравились.** Gamma не умеет анимировать отдельные элементы и вставлять видео в карточку, а правки через custom code применяются частично. Вывод: **Gamma больше не использовать, делать свой HTML.**
2. Тёмная тема с неоном тоже не зашла. Нужна **светлая тема**, неон допустим только акцентом.
3. Пожелания, которые сформулировал пользователь:
   - структура слайдов из `08-presentation.html` (файл из архива переписки команды `ChatExport_2026-11-12.zip`);
   - **меньше текста**;
   - красиво, можно неон;
   - **много живых анимированных элементов**: бегущая строка (marquee), зверьки, pixel art;
   - **мотивы GitHub**: лейблы, граф контрибуций, кнопка Star, diff, список issues, ветки, sha коммита в футере;
   - на слайде архитектуры **иконки и пиктограммы, а не прямоугольники**;
   - каждый слайд должен иметь понятный смысл;
   - анимации на слайдах со скорингом и результатами;
   - без повторов данных между слайдами;
   - тестирование — отдельными слайдами с описанием методики;
   - отдельный эффектный слайд «Спасибо за внимание»;
   - больше скриншотов продукта;
   - **звезда, которая при смене слайда прыгает по элементам слайда и крутится**, а не просто в углу.
4. Баг из прошлых версий: слайд уезжал вправо-вниз. Исправлено центрированием сцены через `translate(-50%,-50%) scale(k)` (см. раздел 4).

## 3. Дизайн-система

```css
--canvas:#fcfcff; --panel:#fff; --subtle:#f3f4fb; --line:#e2e4f0;
--ink:#15142b; --muted:#5c5f77;
--blue:#2f6bff; --violet:#7c3aed; --pink:#ff2e88; --green:#00b86b;
--amber:#ffad00; --orange:#ff7a1a; --star:#ffc400; --gh-green:#2da44e;
--neon: linear-gradient(90deg, var(--blue), var(--violet) 55%, var(--pink));
--ease: cubic-bezier(.2,.7,.2,1);
```

**Шрифты.** Все с кириллицей, вшиты в HTML как base64 woff:
- **Unbounded** — заголовки (`--display`), h2 600 62px;
- **Onest** — основной текст;
- **JetBrains Mono** — код, sha, метки;
- **Press Start 2P** (`--pixel`) — пиксельные акценты.

Mona Sans не подходит: в ней нет кириллицы.

**Цвета уровней score:** low `#00b86b`, medium `#ffad00`, high `#ff7a1a`, critical `#ff2e88`.

**Фон слайда:** мягкие неоновые радиальные пятна по краям плюс точечная сетка как на GitHub (radial-gradient с маской). Текст с градиентом — класс `.neon`.

## 4. Техника (один самодостаточный HTML)

- **Сцена 1920×1080:** `.stage{position:absolute;left:50%;top:50%}` и `transform: translate(-50%,-50%) scale(k)`, где `k=min(innerWidth/1920, innerHeight/1080)`. Это и есть фикс сдвига.
- **Слайды:** `section.slide` с атрибутами `data-ch` (глава) и `data-note` (заметки докладчика). Активный слайд получает класс `.is-on`.
- **Анимации появления:**
  - классы `.in` (подъём), `.grow` (рост по X) и `.pop` (пружинный scale);
  - задержка задаётся через `style="--d:.5"`;
  - анимации проигрываются при каждом входе на слайд.
- **Живые циклы** в функции `play(slide)` через `tween`/`setInterval`, таймеры сбрасываются при смене слайда: циклы примеров скоринга, подсветка шагов тестирования, сканирование строк результатов, «дыхание» KPI.
- **Пиксель-арт:** спрайты рисуются на canvas из массивов строк (функция `sprite(frames, scale)`): сова (машет крылом), боты, искры.
- **Графика:**
  - бегущие строки `fillTicker` (контент дублируется для бесшовного цикла);
  - граф контрибуций на детерминированном ГСЧ;
  - столбцы активности.
- **Прыгающая звезда** (`runHops`, WAAPI):
  - запускается через 950 мс после смены слайда;
  - берёт элементы по селектору `HOPSEL` (h1, h2, .big, .gauge, .popup, .kpi, .diff, .member, .qr и др.);
  - прыгает на 3 случайных, затем приземляется в конец заголовка (через `Range.getClientRects()` последней строки);
  - траектория — квадратичная кривая Безье с вращением на 360° и squash при приземлении, плюс пыль (`.hopdust`);
  - при `prefers-reduced-motion` отключена.
- **Финальный слайд:** фейерверк из пиксельных частиц на canvas.
- **Навигация:**
  - ← → / PgUp / PgDn / Space / Enter, Home / End;
  - клик по правым 2/3 экрана — вперёд, по левой трети — назад;
  - свайп на тач-экране;
  - `N` — заметки докладчика, `F` — полный экран;
  - адрес `#slide-N`;
  - сверху прогресс-бар, строка глав скрыта на обложке;
  - в консоли доступна `window.__go(i)`.

## 5. Сборка и проверка

Файлы в архиве `presentation-kit.zip`:

```
deck.src.html   — исходник с плейсхолдерами {{ONEST}} {{UNBOUNDED}} {{JBM}} {{PS2P}} {{POPUP}} {{MCP}} {{REPORT}}
build.py        — вшивает шрифты (fonts/*.woff) и картинки (popup.jpg, mcp.jpg, report.jpg) в base64 → star-guard-deck.html
shots.py        — Playwright: скриншоты всех слайдов + ошибки консоли (аргумент — задержка в мс)
make_pdf.py     — PDF: 1920×1080 при DSF 1.5, скрыты .ui/.progress/.notes/.hopper, ждёт 5,2 с на слайд, склейка через PIL
fonts/          — Onest, Unbounded, JetBrainsMono, PS2P (woff + ttf)
popup.jpg, mcp.jpg, report.jpg — скриншоты продукта (report обрезан до строк таблицы)
```

Цикл работы:

```bash
python3 build.py              # → star-guard-deck.html (~614 KB)
python3 shots.py 4200         # скриншоты shot_NN.png, проверить "errors []"
python3 make_pdf.py           # → star-guard-deck.pdf
```

Затем опубликовать артефакт через `publish_files`: файл `star-guard-deck.html` под именем `index.html`, slug из начала документа. Перед повторной публикацией взять текущую версию через `get_artifact`.

**Окружение.** Сеть ограничена, поэтому CDN и pip недоступны. Шрифты брались через `git clone` с sparse-checkout из github.com/google/fonts, подмножество глифов делалось `pyftsubset`. Библиотеки для QR нет, поэтому QR оставлен плейсхолдером. Chrome находится в `/usr/bin/google-chrome`, Playwright установлен.

**Проверка.** После каждой правки смотреть все слайды на скриншотах. Типичные проблемы, которые уже ловили:
- перенос заголовка обложки (решено `nowrap`, 132px);
- сова перекрывала счётчик Star;
- слишком высокий popup (обрезан с маской-градиентом);
- наложение текста в gauge;
- звезда не попадала в конец заголовка.
