# Использование

## Офлайн-просмотр

Откройте `dist/index.html` в Chrome, Edge или Firefox. Слайды имеют сцену 1920×1080 и масштабируются с сохранением пропорций. На телефоне для чтения используйте горизонтальную ориентацию.

- `←` / `→`, `PageUp` / `PageDown`, пробел — предыдущий или следующий слайд.
- `Home` / `End` — первый или последний.
- `N` — заметки докладчика. Русская раскладка поддерживается.
- `O` — обзор всех слайдов. `Escape` закрывает обзор.
- `M` — пауза или продолжение анимаций.
- `T` — светлая или тёмная тема с сохранением выбора.
- `F` — полноэкранный режим, если просмотрщик разрешает.
- Клик в левой трети — назад, в остальных двух третях — вперёд.
- Горизонтальный свайп — навигация. Нажатие на ссылку или кнопку не перелистывает слайд.
- `#slide-6` в конце адреса открывает шестой слайд. Нумерация по порядку, а не по историческому HTML id.

## Сборка

Python 3.10+; для HTML не нужны сторонние зависимости:

```bash
python build.py
```

Команда работает из любой текущей папки, пути рассчитываются от расположения скрипта. Сборка перезаписывает `dist/index.html`. Для другого файла используйте `--output /path/deck.html`.

## Скриншоты и PDF

Один раз установите зависимости:

```bash
python -m pip install -r requirements.txt
python -m playwright install chromium
```

Затем:

```bash
python shots.py
python make_pdf.py
```

Скриншоты: `build/shots/light/slide-01.png` … `slide-12.png`. PDF: `dist/star-guard-deck.pdf`. PDF использует печатную вёрстку браузера: текст выделяется, изображения остаются исходными. Экспорт проверяет 12 страниц и наличие текстового слоя. Служебные кнопки и прыгающая звезда скрыты.

`CHROME_PATH` может указывать на установленный Chrome/Chromium. Без переменной сначала выбирается браузер Playwright, затем системный браузер. Не требуется путь `/home/claude` или конкретное имя исполняемого файла.

`python shots.py --theme both` снимает обе темы и создаёт контактные листы.

`python shots.py --live --delay 4500` снимает живые анимации. Обычный режим использует `?export=1`: счётчики и графики сразу в конечном состоянии, таймеры не запускаются. Печать из меню браузера также поддерживается; отключите браузерные колонтитулы.

В GitHub Actions workflow **Check and export presentation** выполняет проверки и сохраняет HTML, PDF и 12 скриншотов в артефакте `star-guard-presentation`. Он не публикует сайт и не меняет видимость репозитория.

## Заполнить команду и QR

В `data/deck.json`:

1. Впишите `name` и `role` в пяти элементах `team_members`.
2. Укажите подтверждённый HTTPS-адрес в `landing_url`.
3. Поместите QR в PNG/JPEG/WebP в `assets/`, укажите относительный путь в `qr_asset`.
4. Убедитесь, что QR действительно кодирует `landing_url`. Сборка проверяет путь и формат, но не декодирует картинку.
5. Запустите сборку и проверьте обложку и финал.

Пустые поля остаются явными заглушками. `server.json` в этот комплект не входит; адрес лендинга из него не угадывается.

## Тема и перемещающийся персонаж

`appearance.default_theme` задаёт исходную тему. По умолчанию она светлая; кнопка темы в настройках или T переключает её и сохраняет выбор локально. `?theme=dark` задаёт тему явно для просмотра или скриншотов. PDF всегда светлый, а после печати экран возвращается к предыдущей теме.

При генерации новой презентации автор самостоятельно выбирает подходящий теме образ и задаёт его в `appearance.traveler.default`. В Star Guard это звезда. `characters` хранит доступные образы, `per_slide` позволяет автору обоснованно менять их по содержанию слайдов. Зритель не выбирает персонажа: в панели, горячих клавишах, URL и сохранённых настройках такого переключателя нет. Для новой темы можно добавить свой короткий символ/эмодзи или реализовать отдельную объёмную модель в исходниках. SVG и HTML в строковое поле `characters` не вставляются.

Настройки хранятся в localStorage, если браузер разрешает его для локальных файлов. При запрете хранилища переключатели продолжают работать в текущем просмотре.

## Управление на телефоне

Нижняя панель содержит подписанные действия «Назад», «Далее», «Слайды» и «Настройки». В настройках доступны анимации, тема, заметки и полный экран. Элементы управления имеют высоту не меньше 44 px.

Системное уменьшение движения учитывается при первом запуске. Если оно отключило эффекты, презентация показывает сообщение и кнопку «Включить». Это явное включение разрешает CSS- и JavaScript-анимации для презентации и сохраняется, если браузер разрешает localStorage. В любой момент можно снова выключить их в настройках. `?motion=system` возвращает учёт системной настройки при этом открытии; `?export=1` всегда остаётся статическим.

Если в предпросмотре нет работающих кнопок, скачайте файл и откройте в полноценном браузере. Статический просмотрщик не может исполнять интерактивную HTML-презентацию.
